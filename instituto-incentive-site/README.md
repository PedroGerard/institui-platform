# Instituto Incentive Site

Site institucional publico do Instituto Incentive.

## Escopo

- Home institucional
- Quem somos
- Areas de atuacao
- Projetos
- Transparencia
- Emendas parlamentares
- Certificacoes e reconhecimentos
- Contato

## Rodar localmente

```bash
npm ci
npm run dev
```

URL padrao:

```text
http://localhost:3000
```

## Build

```bash
npm run build
```

## Deploy

Na Vercel, usar:

- Root Directory: `instituto-incentive-site`
- Install Command: `npm ci`
- Build Command: `npm run build`
