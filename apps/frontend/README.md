# INSTITUI+ Frontend Administrativo

Frontend do sistema de gestao INSTITUI+.

## Escopo

- Dashboard operacional
- Core institucional
- Membros, mandatos, orgaos e assembleias
- Usuarios e contexto operacional
- Tesouraria
- Compras MROSC
- Prestacao de contas
- Documentos oficiais
- Auditoria

## Rodar localmente

Na raiz do repositorio:

```bash
npm run dev:frontend
```

Ou dentro desta pasta:

```bash
npm run dev
```

URL padrao:

```text
http://localhost:3000
```

## Build

Na raiz do repositorio:

```bash
npm run build:frontend
```
